# 家庭管理界面更新 0.2.0

适用于本项目已交付的 OpenWrt 25.12.6 x86/64。使用独立更新包，不需要重新写盘；主题切换不更改网络接口、防火墙、DNS 或 Docker 数据目录。完整固件的下一候选配置已纳入这些包，但本次交付是应用更新包，不是新系统镜像。

## 安装

将更新目录保存在 Windows 电脑上。在 PowerShell 运行同目录的脚本；本项目默认位置为：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "Y:\openwrt\releases\addons\home-ui-0.2.0\Install-Home-UI-0.2.0.ps1"
```

按提示输入软路由管理 IPv4 地址和 root 密码（通常 3 次）。首次 SSH 连接请核对设备指纹。Windows 需具备 OpenSSH 客户端 ssh.exe 和 scp.exe。

安装器核对全部包的 SHA256、路由器版本、架构及剩余空间，再进行离线安装。它会在路由器 `/root/home-ui-backups/` 保存受限权限的配置备份和旧界面缓存，不导出到公共仓库或 Windows。安装后重启网页服务，SSH 和网络接口不重启；浏览器刷新，必要时按 Ctrl+F5。

本地包没有公共源签名，本次安装对这些已校验文件使用 `--allow-untrusted`，不修改全局信任设置、不更新软件源、不批量升级系统包。

## 新入口

- **服务 → 家庭服务**：Docker、群晖/SMB、USB 打印、ZeroTier、BT 下载及家庭上网控制的集中入口。
- **网络 → 常用设置**：常用设置链接、接口 IP/MAC/状态和物理网卡链路速率；WAN/LAN 按现有配置显示，不猜测物理端口用途。编辑仍进入 LuCI 原有页面，保留网络应用确认与回退。
- **服务 → 网络共享挂载**：SMB 客户端配置、状态、重试与卸载。
- **系统 → 系统 → 语言与界面**：Argon 与 Bootstrap 主题选择；Argon 设置也提供浅色、深色和主题外观选项。

Dockerman 继续使用与当前固件配套的维护版，Argon 改善其布局。USB 打印继续使用 p910nd；“家庭服务”中显示服务状态和 USB 打印设备，再进入原有打印配置。未将 lisaac 的旧版管理插件直接覆盖现有 Dockerman。

## 挂载群晖 SMB

1. 群晖开启 SMB3，并创建只访问目标共享的专用账号。
2. 进入“服务 → 网络共享挂载”，填写 NAS IPv4/主机名和共享名；例如地址 `192.168.1.100`、共享 `Downloads`。共享名支持中文，但这一版本不支持名称中含空格或斜杠。
3. 填写账号密码；通常不启用访客。先选 SMB 3.0，群晖支持时可选 3.1.1。
4. 用于 BT 下载时保留挂载点 `/mnt/nas-downloads`，本地访问用户选择 Transmission。
5. 启用并“保存并应用”；查看状态，必要时手动重试。挂载工作在独立服务中进行，失败后台重试，不阻塞路由启动。
6. 在“服务 → 家庭上网控制”配置 NAS 下载存储保护。挂载源填写 `//NAS地址/共享名`，并按原有说明设置共享标识、本地数据盘 UUID、目录与空间检查。确认存储检查通过后再启用下载。

本更新不会自动替你开启下载或填入群晖账号。未挂载时本地挂载目录权限为 0700，避免下载服务把本地目录误当群晖写入。凭据文件及含密码的配置为 0600；密码不出现在 mount.cifs 命令行或状态日志中。

NAS 离线时显示失败并后台重试；已挂载后的实际断线恢复仍受 NAS、网络及 CIFS 内核行为影响，需实机验收。不默认强制卸载或删除未完成下载。“停止并卸载”会先停止使用默认下载挂载点的 Transmission，以降低正在写入时卸载的风险。

## USB 打印

接入 USB 打印机后，在“服务 → 家庭服务”的 USB 打印卡片查看检测到的 `/dev/usb/lpN`，进入打印服务设置设备和端口。电脑端仍需相应打印机驱动。打印机型号兼容、实际打印及扫描能力需分别确认；该更新不把 p910nd 当作扫描服务。

## 恢复界面

若主题显示异常，在 Windows PowerShell 通过 SSH 登录自己的路由器，执行：

```sh
uci set luci.main.mediaurlbase=/luci-static/bootstrap
uci commit luci
/etc/init.d/uhttpd restart
```

刷新网页即可回到保留的 Bootstrap。更新包无需卸载，已有 SMB 数据不会被删除。配置备份位于 `/root/home-ui-backups/0.2.0-日期时间-进程号/`；恢复网络或存储配置前应确认当前业务状态，不直接覆盖正在使用的设置。

## 版本及验证

界面插件 luci-app-home-ui 0.2.0-r1；ZeroTier 页面 0.1.1-r1；Argon 3.1.4 与配套简体中文。新增两个用户态依赖 wget-ssl、libpcre2 来自 OpenWrt 25.12.6 对应的软件仓库，不更换内核模块。

云端在原交付固件的 QEMU 副本中检查安装、登录、桌面/手机布局、原有插件路由及 SMB 凭据权限；结果以随包交付的 validation.json 和截图为准。实机端口、真实群晖挂载/断线、实际打印和长期稳定性仍须现场验证。
