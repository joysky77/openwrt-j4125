# 实机安装准备（2026-11-14）

用户确认：J4125 小主机当前没有运行 OpenWrt。因此按新固件安装准备，不依赖当前小主机的 OpenWrt SSH 会话。此信息不能证明磁盘为空，写盘前仍需检查原有系统和数据。

已知：J4125、8GB 内存、标称 500GB 磁盘、USB 网卡 TL-WDN7200H / 2357:0106。

安装前需实际核对：

1. BIOS 使用 UEFI 还是 Legacy；对应选择镜像，不凭处理器型号推断启动模式。
2. 有线网卡型号、网口数量及每个物理口的映射。
3. 安装目标磁盘型号、序列号、分区及是否有需保留的数据；云编译不执行本机写盘。
4. 家庭宽带拨号方式、现有网段和无线 AP 接法。
5. 群晖共享路径、权限、可用空间以及设备固定地址。
6. 孩子设备标识和早晨恢复时间，打印机型号，代理订阅与 DDNS 服务商。

可先使用闲置 U 盘做隔离启动验证，再决定安装到内置硬盘；制作启动盘会改写该 U 盘，必须先确认盘符和已有数据。初次接入避免与生产路由器 DHCP 或管理地址冲突，设置管理密码后再部署。

如果旧 OpenWrt 设置在另一台设备或已有备份中，后续按项提取迁移，不直接整包覆盖新固件。备份和凭据保存在本地受限目录，不上传公开仓库。
