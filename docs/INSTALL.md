# 安装与验收清单

当前固件是候选版本。写盘、分区、挂载守护及业务配置必须依据目标设备完成，不由云端自动修改真实设备。

## 安装前

核实有线网卡型号、网口映射、UEFI/Legacy、磁盘型号与序列号；保存旧配置及需单独备份的 ZeroTier 身份、下载记录、Docker 数据。旧 eSir 配置按项迁移，不整包覆盖。

500GB 磁盘约 465.66GiB；启动区 256MiB，系统区 4GiB。剩余数据分区 ext4，UUID 挂载 `/srv/data`。目前没有自动分区脚本，安装前必须明确目标磁盘并检查旧数据。更新镜像前验证其对现有数据分区的处理，不宣称整盘刷写保留数据。

本地数据预算：容器及应用 80GiB、WebDAV 缓存目标 40GiB、本地备份 10GiB、可选本地下载 64GiB、其余弹性余量。目录预算不是已实施硬配额。

## 网络与服务

1. 初次启动与生产 LAN 隔离，设置密码，确认 LAN 地址、WAN 网口和拨号方式。
2. 验证 IPv4/IPv6、DHCP、DNS、各网口重启后的稳定映射。
3. USB 2357:0106 无线客户端连接上级 Wi-Fi，手动切换 WAN，验证断线重连。
4. 本地存储确认 UUID 后设置 Docker 数据目录并启用；重要应用数据放本地盘，非关键容器限制资源。
5. 群晖建立专用下载共享，优先 NFS，客户端限定软路由固定 IP；按下载进程身份验证权限。SMB3 为替代方式，不同时挂载到相同路径。凭据仅保存在本机。
6. `incomplete` 与 `complete` 都放在 `/mnt/nas-downloads` 同一共享内。配置和续传记录在本地 `/srv/data/appdata/transmission`，验证服务用户可写。未配置正确前下载保持禁用。
7. 在家庭上网控制页面填写群晖实际挂载源、共享标识、本地数据 UUID；共享根目录 `.openwrt-download-target` 内容与标识一致。提前创建 incomplete/complete 目录及本地配置目录，并授权 transmission 用户。启用存储监督后才启用下载。启动检查放在上游下载 init 自动创建目录之前，监督进程每约 30 秒检查；阻塞探针通过本地继承锁防止重复累积。NFS hard I/O 仍可能阻塞，要验证不会拖慢核心网络启动，不能承诺即时强制暂停。`home-nas-watch` 是可选的服务级自动恢复监督，启用时会重新启动已启用的下载服务；若要手动长期停止服务，同时停用监督。下载器内手动暂停的任务依赖其原生状态保留机制，需实测。
8. 配置代理后再设计 AdGuard Home 与 dnsmasq 的监听、上游、局域网域名和 IPv6 链路，防止循环或端口冲突。避免同时启用多套独立代理/DNS 接管。
9. LibreSpeed 手动测速；明确由路由器发起、出口和是否走代理。群晖性能单独通过 iperf3 或专用文件测试验证，不由公网测速推断。
10. 打印需要真实型号和客户端驱动；DDNS、ZeroTier、UPnP、WOL 按实际范围授权。管理页面、终端、下载 RPC 和 Docker 控制接口只开放给可信 LAN/授权组网访问。

## 孩子夜间禁网

服务 → 家庭上网控制，确认实际 `br-lan` 桥名称、固定 MAC、每天恢复整点。默认关闭，界面预填 07:00 仅为待确认示例。

规则独立于 DNS，在本机选定 LAN 入口针对目标 MAC 丢弃 IPv4/IPv6 包，覆盖代理重定向及已有流。检查周期约 15 秒，存在相应时间误差。禁用流量卸载；如果有其他加速机制需另行核验。验证断电重启、校时前后、跨午夜与恢复时间，不承诺未经实测的精确封禁。

设备改变 MAC、通过其他路由入口或移动数据访问不在当前固定设备规则覆盖内。此规则限制进入路由的网络流量，也可能影响目标设备访问路由器管理服务；同网段设备间流量可能不经过路由，属于不同策略范围。网站/App 精细限制仍需要明确目标并另行验收。

## 验收

- 全部功能页面、业务操作和重启后恢复。
- NAS/WebDAV 断开恢复、权限拒绝、磁盘不足及 DNS/代理故障。
- 下载与容器负载下网络延迟、内存、温度、服务重启计数。
- 连续 48–72 小时代表性负载，保存结果；一次可恢复的升级演练。
- 任何用户文件删除通过明确回收机制；NFS 删除不能默认经过 DSM SMB 回收站，不执行未经核实的自动删除。

完成这些项目后再标记正式可用版本。
