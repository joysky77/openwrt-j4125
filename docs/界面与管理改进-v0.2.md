# 界面与管理改进 v0.2：已实现与交付记录

记录日期：2026-11-20。前版需求对照见“界面与管理改进-v0.1.md”。

本次提供独立的家庭管理界面更新包 0.2.0，不需要重写磁盘。安装目录：`Y:\openwrt\releases\addons\home-ui-0.2.0`；具体安装、SMB 配置和恢复主题方法见该目录安装说明。

## 实现结果

1. Argon 3.1.4 和配套简体中文，保留 Bootstrap 主题。
2. “服务 → 家庭服务”集中展示 Docker、SMB、USB 打印、ZeroTier、Transmission、家庭上网控制和网络诊断。Dockerman 保留当前维护版，未替换为 lisaac 的旧版组件。
3. “服务 → 网络共享挂载”提供单个 SMB3 共享的配置、状态轮询、手动重试和停止卸载。后台独立启动，操作有超时和互斥锁；凭据文件 0600、不在挂载命令行中传递密码；未挂载目录 0700，配置重载会重新应用挂载账号。
4. USB 打印卡片显示 p910nd 服务和检测到的 USB 打印设备，链接现有打印配置页。
5. “网络 → 常用设置”集中提供 WAN/LAN、DHCP、连接设备、Wi-Fi、诊断和高级接口入口，展示接口及物理设备状态。实际编辑仍使用原有 LuCI 保存确认流程。
6. 纳入 ZeroTier 网页插件 0.1.2-r1，以及后续整包构建配置与 Argon 源码锁定。后续整包候选编号为 0.2.0-rc1，本次没有重编新的系统镜像。

## 运行边界

尚未在用户小主机上执行安装。真实群晖认证、共享写权限、NAS 断线恢复、USB 打印以及物理端口对应关系仍待用户安装后配置与验收。SMB 目前只管理一个共享，名字支持中文但不支持空格/斜杠；默认不启用挂载或下载服务。不更换内核模块，不批量更新系统软件包。

安装器在目标路由器保存私有权限的配置备份，切换到 Argon 并重启网页服务，不重启整机或修改 WAN/LAN/DNS。主题异常可按说明切回 Bootstrap；不会删除 NAS 下载数据。
